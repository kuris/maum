# 마음아 놀자 (maum.chatgpts.kr)

불교의 지혜와 마음챙김, 짧은 명상 문구 및 하루 감정 성찰을 제공하는 무료 마음 도구 서비스입니다.

## 주요 기능
- **오늘의 마음**: 매일 새로운 성찰 글귀와 일상 속 실천 과제
- **1분/3분 호흡 명상**: 부드러운 원형 가이드 애니메이션과 웹 오디오 싱잉볼 차임벨
- **불교 지혜 라이브러리**: 8대 핵심 주제(무상, 자비, 평정심, 내려놓음, 인연, 집착 버리기, 감사, 마음챙김)를 쉬운 일상 언어로 재해석
- **마음 카드 뽑기**: 복잡한 마음을 정리해주는 테마별 마음 카드 덱
- **마음 기록장 (감정 일기)**: 오늘의 감정, 내려놓을 것, 감사한 것을 정리하는 3줄 성찰
- **내 기록실**: 비로그인 로컬 스토리지 보관 및 Google 로그인 기반 Supabase 클라우드 동기화

## 기술 스택
- Vanilla HTML / CSS / JavaScript (무프레임워크 초경량 구성)
- Supabase Auth (Google 단일 로그인) & PostgreSQL Database
- Web Audio API (합성 싱잉볼 차임벨)
- Vercel Serverless 배포
